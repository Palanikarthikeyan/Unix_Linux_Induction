/bin - binary file  - executable file (Ex: unix/Linux commands)
		     (ex: /bin/date ; /bin/uname )

/usr/bin - binary file - installed commands/utility  (Ex: unix/Linux commands)

/sbin - binary file - root user only can run - Unix/Linux Admin commands


whereis <command>

/boot - bootloader code + Kernel 

/dev - device files - special device - device related info 

/etc - Configuration directory - Config files are readable by user 


/bin/fileA <== act as a command - executable binary file - user can't read the data

/etc/fileA  <== this is config file not a command - user can read the data (ex: cat /etc/fileA ->OK)

/home - non-root user login directory
/root - root user login directory

/lib
/lib64
--------------// library files ( file.so <== shared object file)

/proc - process details (or) current state of working kernel 


/var/log  ------ log files 
/var/mail
/var/www

/mnt (or) /media (or) /run --- external device mount point directory

----

from Nth Chars to Mth chars

File(F) 
---------
 |-> 3 mode(operation)
     ==================
	read	 r  --> cat filename  
	write	 w  --> vi ; mkdir ; cd ; > ; >> //write operation
	execute	 x

read/write = User level 
             -----------

execute = Kernel level 
          -------------
each file - by 3 users
	    ============
	    |-> user (or) author (or) owner 
	    |-> group - collection of users 
	    |-> others

=============================

Each user can perform 3 operations
		      ============
			read
			write
			execute

user -> read/write/execute

group -> read/write/execute

others -> read/write/execute

 rwxrwxrwx
 ===___.....
  |  |    |--->others
  |  group
  user

 rw-rw-r--
 -----------
  |->user - can do read/write
  |->group - can do read/write
  |
  |->others - read only



How to assign the file permission?
       ======
chmod user_details + mode filename 
				
Give user execute permission to p1 file
     ---- ======= 
chmod u+x p1
 
To remove execute permission from user 
   =======
chmod u-x p1
